# Instalação

```console
# clone o repositorio 
$ git clone https://github.com/AlissonDvorak/PdfReader.git 

# encontre o local de download
$ cd pdfReader

# instale os requerimentos 
$ pip install -r requirements.txt

```

```console
# Utilizacao 
## colocar o pdf que deseja extrair na pasta PDF

$ python main.py

selecionar a extracao desejada
opcoes 1 e 2 

```
